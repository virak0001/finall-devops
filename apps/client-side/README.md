# Frontend Service

This Nuxt 4 app renders the DevOps Learning Hub dashboard and proxies backend calls through Nitro server routes.

Useful scripts:

```bash
npm run dev
npm run build
npm run preview
npm run typecheck
```

For the full project workflow, Docker Compose, and Docker Swarm deployment, use the root [README](/home/virak/Desktop/MSIT-UP-2025/DevOps/README.md).
